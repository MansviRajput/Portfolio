# Mansvi Rajput Portfolio

A polished single-page portfolio website built with HTML, CSS, and JavaScript.

## Run locally

From this folder, start a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` - main portfolio structure and content
- `styles.css` - visual design, layout, responsiveness, and animations
- `script.js` - scroll reveals, active navigation, cursor glow, progress bar, and card tilt

## Content included

- Introduction and education
- About section
- Experience timeline
- Project cards
- Technical skills
- Contact section
